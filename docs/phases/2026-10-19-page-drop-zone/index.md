# page-drop-zone

A PDF can only be dropped on the small upload panel; a drop anywhere else on the page is ignored. The user wants the whole page to accept the drop, with a full-screen overlay while a file is dragged over the window. Layout unchanged. Frontend only. Issue #46, follow-up to #44.
