# Ideate — github-readme

_Entered 2026-10-21._

**Problem:** someone who opens github.com/kshitijkamble-oss/pdf-image-extractor sees a file list and nothing else. No README, no description, no topics. They cannot tell what the app does, where to try it, or how to run it.

**For whom:** visitors to the repo (a reviewer, a teammate, the user's future self).

**Success looks like:** within a few seconds on the repo page, a visitor knows (1) what the app does, (2) the live link, (3) how to run it locally, and (4) how the repo is laid out. The sidebar shows a one-line description and a few topics.

**If we don't:** the repo looks unfinished, and anyone new has to read the code to learn the basics.

**Out of scope:** changing the app itself; screenshots that need new hosting.
